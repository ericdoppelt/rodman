# Backlog

After finishing work that resolves an open item in `BACKLOG.md`, remove/update that item in the same change — don't leave it stale.

# Cost

Prefer free options when adding new data sources or third-party APIs — no credit card required, wherever possible. If the only good option requires payment or a card on file, flag it and ask before signing up.

# Design decisions

When we make a notable design decision (a real trade-off between options, not an obvious/only choice), flag it to the user first — "that's a meaningful design decision, let's talk through pros/cons" — before proceeding. Once we've discussed it, record it as a new file in `docs/decisions/NNNN-title.md`: context, options considered, decision, trade-off.
